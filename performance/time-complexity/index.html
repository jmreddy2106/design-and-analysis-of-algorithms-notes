    Time Complexity¶

    Definition¶

    Time complexity measures how running time grows with input size n.

    We write:

    \[ T(n) = O(f(n)) \]

    Where f(n) describes the growth.

    Common Time Complexities¶

    Complexity Name Typical Example
    O(1) Constant array index access
    O(log n) Logarithmic binary search
    O(n) Linear linear search
    O(n log n) Linearithmic merge sort
    O(n^2) Quadratic bubble sort
    O(2^n) Exponential subset generation
    O(n!) Factorial brute-force TSP

    How to Estimate Time Complexity¶

    Rule 1: Single Loop → O(n)¶

    for i in range(n):
    print(i)
    \[ T(n) = O(n) \]

    Rule 2: Nested Loops → Multiply¶

    for i in range(n):
    for j in range(n):
        print(i, j)
    \[ T(n) = O(n^2) \]

    Rule 3: Halving / Doubling → O(log n)¶

    while n > 1:
    n = n // 2
    \[ T(n) = O(\log n) \]

    Worked Example: Linear Search¶

    def linear_search(arr, key):
    for x in arr:
        if x == key:
            return True
    return False

    Worst case: key not found → checks all n items:

    \[ T(n) = O(n) \]

    Worked Example: Binary Search (Sorted Array)¶

    Binary search halves the search space each step:

    \[ T(n) = O(\log n) \]

    Constant Factors and Lower-Order Terms¶

    \[ 3n^2 + 10n + 5 \in O(n^2) \]

    Because for large n, n² dominates.

    Mini Practice¶

    Find time complexity:

    1. for i in range(n): for j in range(i): ...
    2. for i in range(n): while k > 1: k = k//2

    Expected: 1. O(n^2) 2. O(n log n)
