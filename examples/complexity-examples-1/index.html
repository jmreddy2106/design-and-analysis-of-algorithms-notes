    Complexity Analysis Examples¶

    Practice analyzing time and space complexity with these comprehensive examples.

    Basic Examples¶

    Example 1: Simple Operations¶

    def example1(n):
    x = 5           # O(1)
    y = x + 10      # O(1)
    return y        # O(1)

    Analysis: - 3 constant-time operations - Time: O(1) - Space: O(1)

    Example 2: Single Loop¶

    def example2(n):
    total = 0               # O(1)
    for i in range(n):      # O(n)
        total += i          # O(1) × n times
    return total            # O(1)

    Analysis: - Loop runs n times - Each iteration: O(1) - Time: O(n) - Space: O(1)

    Example 3: Nested Loops¶

    def example3(n):
    count = 0                   # O(1)
    for i in range(n):          # O(n)
        for j in range(n):      # O(n) for each i
            count += 1          # O(1)
    return count                # O(1)

    Analysis: - Outer loop: n iterations - Inner loop: n iterations per outer - Total: n × n = n² - Time: O(n²) - Space: O(1)

    Example 4: Two Sequential Loops¶

    def example4(n):
    # First loop
    for i in range(n):      # O(n)
        print(i)

    # Second loop
    for j in range(n):      # O(n)
        print(j)

    Analysis: - First loop: O(n) - Second loop: O(n) - Total: O(n) + O(n) = O(2n) = O(n) - Time: O(n) - Space: O(1)

    Rule

    Sequential operations add: O(a) + O(b) = O(a + b)

    Example 5: Different Loop Sizes¶

    def example5(n, m):
    for i in range(n):      # O(n)
        print(i)

    for j in range(m):      # O(m)
        print(j)

    Analysis: - Can't assume n = m - Time: O(n + m) - Space: O(1)

    Logarithmic Complexity¶

    Example 6: Binary Search Pattern¶

    def example6(n):
    i = 1
    while i < n:
        print(i)
        i *= 2      # Double each time

    Analysis: 

    Iteration 1: i = 1
Iteration 2: i = 2
Iteration 3: i = 4
Iteration 4: i = 8
...
Iteration k: i = 2^k

When does it stop? When 2^k >= n
Therefore: k = log₂(n)
    - Time: O(log n) - Space: O(1)

    Example 7: Halving Pattern¶

    def example7(n):
    while n > 1:
        print(n)
        n //= 2     # Halve each time

    Analysis: 

    n → n/2 → n/4 → n/8 → ... → 1
Number of divisions until reaching 1 = log₂(n)
    - Time: O(log n) - Space: O(1)

    Complex Loop Patterns¶

    Example 8: Nested Loop with Dependency¶

    def example8(n):
    for i in range(n):          # Outer: n times
        for j in range(i):      # Inner: i times
            print(i, j)

    Analysis: 

    When i = 0: inner runs 0 times
When i = 1: inner runs 1 time
When i = 2: inner runs 2 times
...
When i = n-1: inner runs n-1 times

Total = 0 + 1 + 2 + ... + (n-1)
     = n(n-1)/2
     = (n² - n)/2
     = O(n²)
    - Time: O(n²) - Space: O(1)

    Example 9: Loop with Multiplication¶

    def example9(n):
    for i in range(n):              # O(n)
        for j in range(n * n):      # O(n²) for each i
            print(i, j)

    Analysis: - Outer: n iterations - Inner: n² iterations per outer - Total: n × n² = n³ - Time: O(n³) - Space: O(1)

    Example 10: Multiple Nested Loops¶

    def example10(n):
    for i in range(n):      # O(n)
        for j in range(n):  # O(n)
            for k in range(n):  # O(n)
                print(i, j, k)

    Analysis: - Three nested loops, each O(n) - Total: n × n × n = n³ - Time: O(n³) - Space: O(1)

    Space Complexity Examples¶

    Example 11: Array Creation¶

    def example11(n):
    arr = [0] * n       # Create array of size n
    return arr

    Analysis: - Array with n elements - Time: O(n) - to initialize - Space: O(n) - array storage

    Example 12: 2D Array¶

    def example12(n):
    matrix = [[0] * n for _ in range(n)]
    return matrix

    Analysis: - Matrix: n × n elements - Time: O(n²) - to create - Space: O(n²) - matrix storage

    Example 13: Recursion Stack¶

    def example13(n):
    if n <= 0:
        return
    print(n)
    example13(n - 1)    # Recursive call

    Analysis: - Recursion depth: n - Each call uses stack space - Time: O(n) - Space: O(n) - call stack

    Example 14: Recursive with Multiple Calls¶

    def fibonacci(n):
    if n <= 1:
        return n
    return fibonacci(n-1) + fibonacci(n-2)

    Analysis: 

    fibonacci(5)
├── fibonacci(4)
│   ├── fibonacci(3)
│   │   ├── fibonacci(2)
│   │   │   ├── fibonacci(1) → 1
│   │   │   └── fibonacci(0) → 0
│   │   └── fibonacci(1) → 1
│   └── fibonacci(2)
│       ├── fibonacci(1) → 1
│       └── fibonacci(0) → 0
└── fibonacci(3)
    ├── fibonacci(2)
    │   ├── fibonacci(1) → 1
    │   └── fibonacci(0) → 0
    └── fibonacci(1) → 1

Height of tree: n

Number of nodes: ~2^n
    - Time: O(2ⁿ) - exponential! - Space: O(n) - max recursion depth

    Mixed Complexity Examples¶

    Example 15: Loop with Inner Binary Search¶

    def example15(arr, targets):
    """
    arr: sorted array of n elements
    targets: array of m elements
    """
    results = []
    for target in targets:              # O(m)
        result = binary_search(arr, target)  # O(log n)
        results.append(result)
    return results

    Analysis: - Outer loop: m times - Binary search: O(log n) each time - Time: O(m log n) - Space: O(m) - results array

    Example 16: Sorting in a Loop¶

    def example16(arrays):
    """
    arrays: list of k arrays, each of size n
    """
    for arr in arrays:      # O(k)
        arr.sort()          # O(n log n)

    Analysis: - k arrays to sort - Each sort: O(n log n) - Time: O(k × n log n) - Space: Depends on sorting algorithm

    Tricky Examples¶

    Example 17: Decreasing Loop¶

    def example17(n):
    i = n
    while i > 0:
        print(i)
        i //= 2

    Analysis: - Starts at n, halves each time - Same as Example 7 - Time: O(log n) - Space: O(1)

    Example 18: Multiple Variables¶

    def example18(n):
    i = 1
    j = n
    while i < j:
        print(i, j)
        i *= 2      # i doubles
        j //= 2     # j halves

    Analysis: - i: 1, 2, 4, 8, ... - j: n, n/2, n/4, n/8, ... - They meet around √n - Time: O(log n) - Space: O(1)

    Example 19: Sqrt Loop¶

    def example19(n):
    i = 2
    while i * i <= n:
        print(i)
        i += 1

    Analysis: - Loop runs while i² ≤ n - Equivalently: while i ≤ √n - Time: O(√n) - Space: O(1)

    Example 20: Harmonic Series¶

    def example20(n):
    count = 0
    i = 1
    while i <= n:
        j = i
        while j <= n:
            count += 1
            j += i      # Increment by i
        i += 1

    Analysis: 

    When i = 1: inner runs n times
When i = 2: inner runs n/2 times
When i = 3: inner runs n/3 times
...

Total = n(1 + 1/2 + 1/3 + ... + 1/n)
     = n × H(n)  where H(n) is harmonic series
     = n × O(log n)
    - Time: O(n log n) - Space: O(1)

    Practice Problems¶

    Problem 1¶

    def mystery1(n):
    for i in range(n):
        for j in range(i, n):
            print(i, j)
    Answer

    Time: O(n²)

    Explanation: 

    When i = 0: inner runs n times
When i = 1: inner runs n-1 times
When i = 2: inner runs n-2 times
...
Total = n + (n-1) + (n-2) + ... + 1
     = n(n+1)/2
     = O(n²)

    Problem 2¶

    def mystery2(n):
    i = n
    while i >= 1:
        print(i)
        i //= 2
    Answer

    Time: O(log n)

    Explanation: Halves each iteration, classic logarithmic pattern.

    Problem 3¶

    def mystery3(n):
    for i in range(n):
        j = 1
        while j < n:
            print(i, j)
            j *= 2
    Answer

    Time: O(n log n)

    Explanation: - Outer loop: n times - Inner loop: log n times - Total: n × log n

    Problem 4¶

    def mystery4(arr):
    n = len(arr)
    temp = [0] * n
    for i in range(n):
        temp[i] = arr[i] * 2
    return temp
    Answer

    Time: O(n)
    Space: O(n)

    Explanation: - Loop: n iterations - Temp array: n elements

    Problem 5¶

    def mystery5(n):
    if n <= 1:
        return 1
    return mystery5(n-1) + mystery5(n-1)
    Answer

    Time: O(2ⁿ)
    Space: O(n)

    Explanation: - Two recursive calls per invocation - Forms binary tree with height n - Number of nodes: 2ⁿ - 1

    Summary Cheat Sheet¶

    Pattern Example Complexity
    Single loop for i in range(n) O(n)
    Nested loops for i... for j... O(n²)
    Halving while i > 0: i //= 2 O(log n)
    Doubling while i < n: i *= 2 O(log n)
    Sqrt pattern while i*i < n O(√n)
    Binary recursion f(n-1) + f(n-1) O(2ⁿ)
    Linear recursion f(n-1) O(n)
    Divide & conquer Merge sort O(n log n)

    Tips for Analysis¶

    Quick Rules

    1. Sequential blocks → Add complexities
    2. Nested blocks → Multiply complexities
    3. Log appears when: halving, doubling, divide-and-conquer
    4. Count loop iterations carefully
    5. Ignore constants in Big-O
    6. Keep dominant term only
    7. Different inputs = different variables
